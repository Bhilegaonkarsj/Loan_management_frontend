💰 Loan Management System

A full-stack Loan Management System built using Spring Boot, MySQL, HTML/CSS/JavaScript, and RESTful APIs. This project supports user registration, loan scheme display, account linking, and transaction tracking.

🛠️ Tech Stack
Backend: Spring Boot, Java, RESTful APIs

Frontend: HTML, CSS, JavaScript

Database: MySQL (Railway DB or local)

Tools: Spring Tool Suite (STS), VS Code, Git

✅ Features
🔐 User Sign-Up and Login (Token-based authentication)

👤 Profile Management with Image Upload

🏦 Account Linking with UPI

💼 Loan Schemes Display (Tabs with Images)

💳 Apply for Loan (based on scheme)

💸 View Loan Transactions

📊 Dashboard for logged-in users

📡 Microservices architecture (in progress)

🚀 Getting Started
Backend (Spring Boot)
Clone the repository

Open in Spring Tool Suite or VS Code

Update application.properties with your DB config

Run UserServiceApplication.java

Frontend
Navigate to /frontend

Open signup.html or dashboard.html in browser

Ensure backend is running for API connectivity
